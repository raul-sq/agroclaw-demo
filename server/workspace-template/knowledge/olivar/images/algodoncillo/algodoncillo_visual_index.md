# Índice diagnóstico visual — algodoncillo del olivo

## Descripción general de la carpeta

Esta carpeta reúne referencias visuales documentadas sobre **algodoncillo del olivo** (*Euphyllura olivina*) para uso interno de diagnóstico orientativo.

El conjunto incluye imágenes centradas en:

- síntomas visibles sobre **brotes tiernos e inflorescencias**;
- **detalle del insecto** o de sus formas juveniles;
- **colonias o presencia múltiple** en hojas, brotes o floración;
- casos con posible **melaza o negrilla asociada**.

Estas referencias sirven como apoyo para comparar imágenes de campo y mejorar la recuperación visual interna, pero no sustituyen la valoración agronómica en parcela ni las fichas individuales de cada imagen.

## Referencias más útiles para diagnóstico rápido

Las referencias más útiles para un **diagnóstico visual rápido en campo** son:

1. **`algodoncillo_01.md` + `algodoncillo_01.jpg`**  
   Muy útil cuando el usuario describe **olivo en floración** con **masas blancas algodonosas sobre brotes e inflorescencias**.

2. **`algodoncillo_02.md` + `algodoncillo_02.jpg`**  
   Muy útil cuando, además del síntoma algodonoso, aparecen **hojas jóvenes afectadas** o signos compatibles con **melaza/negrilla asociada**.

3. **`algodoncillo_06.md` + `algodoncillo_06.jpg`**  
   Muy útil cuando se quiere reforzar la sospecha visual viendo **insecto + síntoma** en la misma referencia.

## Referencias más útiles para confirmar el insecto

Las referencias más útiles para **confirmar visualmente el insecto o sus fases** son:

1. **`algodoncillo_04.md` + `algodoncillo_04.jpg`**  
   Referencia clara del psílido asociado al algodoncillo en detalle cercano.

2. **`algodoncillo_05.md` + `algodoncillo_05.jpg`**  
   Útil para reconocer **ninfas o individuos jóvenes** en tejido tierno.

3. **`algodoncillo_06.md` + `algodoncillo_06.jpg`**  
   Útil para observar **adultos junto a secreciones algodonosas**, reforzando la interpretación del cuadro.

## Nota para AgroClaw

AgroClaw debe usar este índice:

- como **guía interna de recuperación visual** para localizar rápidamente las referencias más útiles según el tipo de imagen recibida;
- **sin sustituir las fichas individuales**, que contienen el contexto descriptivo completo de cada referencia;
- **sin emitir diagnóstico definitivo solo por imagen**, aunque la coincidencia visual sea alta;
- **sin recomendar tratamiento** si antes no se valora la **intensidad**, la **fenología** y el **contexto de parcela**.

# Verticilosis del olivo — referencia visual 03

- **Cultivo:** olivo
- **Órgano afectado / contexto:** rama / brote / copa parcial
- **Diagnóstico orientativo:** verticilosis del olivo
- **Nombre científico:** *Verticillium dahliae*
- **Ruta de imagen asociada:** `knowledge/olivar/images/verticilosis/verticilosis_03.jpg`

## Descripción visual

La imagen muestra una rama de olivo con síntomas compatibles con verticilosis:

- secado acusado de varios brotes o ramillas;
- hojas secas, enrolladas o completamente desecadas;
- contraste claro entre partes aún verdes y partes ya afectadas;
- aspecto de muerte regresiva en una zona concreta de la copa.

## Valor diagnóstico visual

Esta imagen tiene **valor orientativo medio-alto** para reconocer un cuadro compatible con verticilosis cuando se observan:

- ramillas secas o marchitas;
- secado localizado en una parte del árbol;
- contraste entre tejido vivo y tejido ya colapsado;
- progresión visible del daño desde brotes o ramas afectadas.

## Interpretación agronómica

La verticilosis del olivo puede manifestarse como:

- secado parcial de ramas;
- decaimiento localizado;
- muerte regresiva de brotes;
- pérdida progresiva de vigor en partes del árbol.

Esta referencia es útil para ilustrar una expresión del problema a **escala de rama o copa parcial**, distinta de la imagen de árbol completamente seco o del corte de madera.

## Limitaciones diagnósticas

Aunque la imagen es útil como referencia de campo, conviene recordar que:

- el secado de brotes o ramas no es exclusivo de verticilosis;
- puede ser necesario diferenciarlo de otros problemas de decaimiento, daño fisiológico o afecciones de madera;
- la confianza diagnóstica aumenta si se combina con síntomas a escala de árbol y, cuando proceda, con observación interna de la madera;
- la imagen por sí sola no sustituye la confirmación técnica.

## Nota para AgroClaw

Cuando AgroClaw utilice esta referencia visual:

- debe tratarla como **evidencia orientativa de secado parcial compatible con verticilosis**, no como diagnóstico definitivo por sí sola;
- debe destacar el contraste entre ramas verdes y ramas secas;
- debe usarla para explicar que la verticilosis puede expresarse de forma localizada antes de afectar al árbol completo;
- debe recomendar confirmación técnica en campo;
- debe indicar un nivel de confianza visual moderado si no existen síntomas complementarios.

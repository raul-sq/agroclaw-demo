# Repilo del olivo — referencia visual 02

- **Cultivo:** olivo
- **Órgano afectado:** hoja
- **Diagnóstico orientativo:** repilo del olivo
- **Nombre científico:** *Fusicladium oleaginum*
- **Ruta de imagen asociada:** `knowledge/olivar/images/repilo/repilo_02.jpeg`

## Descripción visual

La imagen muestra una hoja de olivo con síntomas compatibles con repilo:

- manchas circulares oscuras bien visibles;
- halos amarillentos alrededor de las lesiones;
- zonas necróticas o deprimidas en el centro de algunas manchas;
- contraste entre tejido verde aún funcional y tejido amarilleado o afectado.

## Valor diagnóstico visual

Esta imagen tiene **alto valor orientativo** para identificar repilo en hoja cuando se observan:

- lesiones redondeadas oscuras;
- halo clorótico o amarillento;
- patrón repetido de manchas circulares sobre el limbo foliar.

## Posibles consecuencias agronómicas

Cuando la afección progresa, el repilo puede relacionarse con:

- amarilleamiento foliar;
- debilitamiento del árbol;
- caída prematura de hojas;
- reducción de la masa foliar activa.
